# Fotos de Cabañas El Bosque

Para cambiar una foto, reemplace el archivo en `fotos/` con el mismo nombre, en WebP. Cada foto lleva su miniatura con `-600` (600 px de ancho), por ejemplo `portada.webp` y `portada-600.webp`. El logo no lleva miniatura.

| Archivo | Qué foto va | Dónde sale |
|---|---|---|
| `logo.webp` | Logo de las cabañas, fondo transparente. Todavía no existe: al ponerlo, reemplaza solo el nombre escrito | Encabezado de todas las páginas |
| `portada` | Foto horizontal de montaña o bosque, con el borde de abajo oscuro: ese borde se refleja en el agua | Inicio y Reservar, arriba |
| `cabana-1` | Cabaña para 2 | Inicio, Cabañas |
| `cabana-2` | Cabaña para 4 | Inicio, Cabañas |
| `cabana-3` | Cabaña familiar | Inicio, Cabañas |
| `jardin` | Jardín completo, horizontal | El jardín, arriba |
| `estanque` | Estanque de peces visto desde arriba, horizontal | Inicio ("Toque el agua"), El jardín, Reservar (fondo de las tres piedras) |
| `colonia-tovar` | Una calle o casa del pueblo | Inicio, Qué hacer |
| `galeria-1` | Foto vertical de un cuarto | Galería |
| `galeria-2` | Foto vertical de una cabaña | Galería, Inicio ("Aquí lo atienden sus dueños") |
| `galeria-3` | Foto horizontal del agua | Galería, Inicio (tarjeta Galería), El jardín, hoja "Más", y arriba en Galería |
| `galeria-4` | Paisaje de la Colonia | Galería, Cabañas (cierre), Cómo llegar |
| `galeria-5` | Estanque con piedras o plantas | Galería, El jardín |
| `galeria-6` | Foto horizontal de los peces | Galería, El jardín |
| `galeria-7` | Flores o detalle del jardín | Galería, El jardín |
| `galeria-8` | Entrada o camino de llegada | Galería, Inicio (tarjeta Cómo llegar), Cómo llegar, hoja "Más" |

Otras fotos que no hace falta cambiar: `bosque` (cabeza de Cabañas y cierres), `iglesia`, `restaurantes` y `fresas` (Qué hacer e Inicio), `compartir.jpg` (vista del enlace al mandarlo por WhatsApp, 1200 x 630).

Al poner fotos propias, quite los créditos de esas fotos en la Galería.
